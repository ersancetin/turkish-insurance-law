# Rehberler

Bu klasördeki dosyalar **resmî metin değildir**. `belgeler/` altındaki birincil
kaynakları anlamayı kolaylaştıran derleme notlarıdır.

> [!WARNING]
> Rehberler derleme/özet niteliğindedir, **doğrulanmamıştır** ve hukuki tavsiye
> içermez. Her ifade, `belgeler/` altındaki ilgili birincil kaynaktan teyit
> edilmelidir. Sayısal değerler (parasal sınırlar, tarifeler, limitler) **yıllık
> değişir** — kullanmadan önce `son_guncelleme` tarihine bakın.

| Klasör | İçerik |
| --- | --- |
| `kavramlar/` | Terim sözlüğü, kavram haritaları |
| `surecler/` | Hasar, başvuru, tahkim, dava süreç akışları |
| `hesaplamalar/` | Tazminat kalemleri ve hesap yöntemi notları |
| `karsilastirmalar/` | Branş/teminat karşılaştırma tabloları |
