# Tazminat Hesabı Notları (Trafik / Sorumluluk)

> [!WARNING]
> Derleme özet — doğrulanmamıştır, hukuki tavsiye değildir. Hesap yöntemleri
> içtihatla şekillenmektedir; bilirkişi raporu ve güncel Yargıtay kararı esastır.

## 1. Hukuki çerçevedeki kırılma: AYM kararı

Anayasa Mahkemesi **E.2021/82, K.2022/167** (29.12.2022; RG 14.02.2023) kararıyla,
2918 sayılı KTK m.90/1'in ikinci cümlesi ile m.90/2 iptal edildi. Bu hükümler,
ZMSS kapsamındaki **destekten yoksun kalma**, **sürekli sakatlık** ve **değer
kaybı** tazminatlarının hesabını genel şartlara/ eklerine bağlıyordu.

**Sonuç:** Tazminat hesabında genel şart ekleri değil, **TBK'nın haksız fiil
rejimi** (m.49 vd., 53, 54, 55) esas alınır.

> [!CAUTION]
> Bu, poliçenin **limitlerini** ortadan kaldırmaz. Sigortacının sorumluluğu
> poliçe teminat limitiyle sınırlıdır; limiti aşan kısım işletene/sürücüye kalır
> (İMM varsa oraya sirayet eder).

## 2. Destekten yoksun kalma tazminatı (TBK m.53)

**Kim talep edebilir?** Fiilen destek gören herkes — mirasçı olması şart değil;
eş, çocuk, anne-baba tipik; nişanlı/ evlilik dışı birliktelik de kabul edilebilir.

**Hesap unsurları:**

| Unsur | Uygulama notu |
| --- | --- |
| Gelir | Belgelenen net gelir; yoksa **net asgari ücret** |
| Bakiye ömür | Yaşam tablosu (uygulamada **TRH 2010**) |
| Aktif/pasif dönem | Aktif: çalışma çağı; pasif: emeklilik sonrası (asgari ücret üzerinden) |
| Destek payları | Eş ve çocuklara paylaştırma; yaygın uygulama "2 pay eş + 1'er pay çocuk" benzeri formüller |
| Bilinen/bilinmeyen dönem | Bilinen dönem gerçek gelirle, bilinmeyen dönem progresif rant / iskonto ile |
| İskonto (teknik faiz) | Peşin sermaye değerine indirgeme; oran içtihatla tartışmalı |
| Kusur indirimi | Ölenin kusuru oranında indirim |
| Denkleştirme | SGK'dan bağlanan gelirin peşin sermaye değeri mahsup edilir (5510 m.21 çerçevesinde) |
| Hatır taşıması | Uygulamada makul oranda (%20 civarı) indirim tartışması |

## 3. Sürekli sakatlık tazminatı (TBK m.54)

| Unsur | Uygulama notu |
| --- | --- |
| Maluliyet oranı | **Erişkinler İçin Engellilik Değerlendirmesi Hakkında Yönetmelik** (olay tarihine göre yürürlükteki mevzuat) uyarınca hastane kurul raporu |
| Gelir | Net gelir / net asgari ücret |
| Bakiye ömür | TRH 2010 |
| Hesap | Aktif + pasif dönem çalışma gücü kaybı |
| Geçici iş göremezlik | Ayrı kalem; iyileşme süresi boyunca gelir kaybı |
| Bakıcı gideri | Maluliyet derecesine göre ayrıca istenebilir |
| Tedavi giderleri | Trafik kazalarında **SGK'ya devredilmiştir** (KTK geçici m.1) — sigortacıdan ayrıca istenemez, istisnalar tartışmalı |

## 4. Araç değer kaybı

**Tanım:** Kaza sonucu onarılan aracın, kaza öncesi hasarsız piyasa değeri ile
onarım sonrası piyasa değeri arasındaki fark.

| Konu | Not |
| --- | --- |
| Hesap yöntemi | Genel şart ekindeki formülün bağlayıcılığı **yargı kararlarıyla tartışmalı hâle geldi**; uygulamada bilirkişi, kaza tarihi itibarıyla hasarsız/hasarlı değer farkını belirler |
| Değerlendirme tarihi | Kaza tarihi (kural) |
| Kim isteyebilir | Zarar gören araç maliki; ZMSS'den talep edilir |
| Kasko | Kasko poliçesi kural olarak **kendi aracının** değer kaybını karşılamaz (özel şart hariç) |
| Sınırlar | Ağır hasarlı/ pert araçta değer kaybı yerine tam hasar rejimi |

## 5. Maddi hasar (araç onarımı)

| Konu | Not |
| --- | --- |
| Onarım bedeli | Piyasa rayici; orijinal/eşdeğer parça tartışması |
| Yıpranma payı | Yeni parça takılması zenginleşme yaratıyorsa indirim (özellikle lastik, akü, egzoz) |
| Pert (tam hasar) | Onarım bedeli > sovtaj sonrası değer → araç rayiç değeri − sovtaj |
| İkame araç / kazanç kaybı | Ticari araçlarda belgelenen kazanç kaybı; ZMSS'de teminat kapsamı poliçeye göre değişir |

## 6. Faiz ve yargılama giderleri

| Konu | Not |
| --- | --- |
| Temerrüt başlangıcı | Sigortacı bakımından KTK m.97 başvurusundan sonraki 15 günün dolması / TTK m.1427 süreleri |
| Faiz türü | Ticari iş niteliğine göre avans faizi tartışması; tüketici işlemlerinde yasal faiz |
| Vekâlet ücreti | Tahkimde ayrı tarife; mahkemede AAÜT |
