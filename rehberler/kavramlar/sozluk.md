# Sigorta Hukuku Terim Sözlüğü

> [!WARNING]
> Derleme özet. Resmî tanımlar için ilgili kanun/yönetmelik maddesine bakın.

## Sözleşmenin tarafları ve ilgilileri

| Terim | Açıklama | Dayanak |
| --- | --- | --- |
| **Sigortacı** | Prim karşılığında riziko teminatı veren, ruhsatlı şirket | 5684; TTK m.1401 |
| **Sigorta ettiren** | Sözleşmeyi yapan, prim borçlusu | TTK m.1401 vd. |
| **Sigortalı** | Menfaati teminat altına alınan kişi | TTK m.1454 vd. |
| **Lehtar** | Can sigortalarında tazminatı almaya yetkili kişi | TTK m.1490 vd. |
| **Zarar gören / üçüncü kişi** | Sorumluluk sigortalarında doğrudan dava hakkı olan | TTK m.1478; KTK m.97 |
| **Acente / broker / eksper** | Sigorta aracıları ve hasar tespit uzmanı | 5684 m.21-23; ilgili yönetmelikler |

## Sözleşme ve teminat kavramları

| Terim | Açıklama |
| --- | --- |
| **Riziko** | Gerçekleşmesi muhtemel, teminat konusu olay |
| **Genel şart** | Düzenleyici otoritenin belirlediği, sözleşmeye zorunlu olarak giren tip şartlar |
| **Özel şart** | Genel şartı sigortalı lehine değiştiren/ tamamlayan sözleşme hükümleri |
| **Kloz** | Teminatı genişleten ya da daraltan ek metin (ör. GLKHHKNH, terör, deprem) |
| **Teminat dışı hâller** | Sigortacının sorumlu olmadığı, genel şartta sayılan hâller |
| **Muafiyet** | Sigortalının kendi üzerinde kalan zarar payı (tenzili / entegral) |
| **Sürprim** | Riskin yüksekliği nedeniyle alınan ek prim |
| **Eksik sigorta** | Sigorta bedelinin gerçek değerin altında olması → oransal ödeme |
| **Aşkın sigorta** | Sigorta bedelinin gerçek değeri aşması |
| **Zeyilname** | Poliçede sonradan yapılan değişikliğin belgesi |
| **Halefiyet (rücu)** | Ödeme yapan sigortacının, sorumluya karşı sigortalının haklarına geçmesi (TTK m.1472) |
| **Beyan yükümlülüğü** | Sözleşme kurulurken rizikoyu etkileyen bilgileri bildirme yükümü (TTK m.1435 vd.) |
| **İhbar yükümlülüğü** | Riziko gerçekleştiğinde bildirim (TTK m.1446: kural olarak beş iş günü) |

## Trafik ve motorlu araç

| Terim | Açıklama |
| --- | --- |
| **ZMSS / trafik sigortası** | Zorunlu Mali Sorumluluk Sigortası; işletenin üçüncü kişilere verdiği zararı teminat altına alır |
| **İMM** | İhtiyari Mali Sorumluluk Sigortası; ZMSS limitini aşan kısım için |
| **Kasko** | Sigortalının kendi aracındaki zarar |
| **İşleten** | Araç üzerinde fiilî hâkimiyeti bulunan, ekonomik yarar sağlayan kişi (KTK m.3) |
| **Değer kaybı** | Onarılan aracın kaza öncesi ile sonrası piyasa değeri farkı |
| **Pert (tam hasar)** | Onarım bedelinin araç değerini aşması; hükümsüz/ekonomik pert ayrımı |
| **Destekten yoksun kalma** | Ölenin desteğinden yoksun kalanların maddi zararı (TBK m.53) |
| **Sürekli sakatlık tazminatı** | Beden gücü kaybı nedeniyle çalışma gücü zararı (TBK m.54) |
| **Hatır taşıması** | Karşılıksız/ nezaketen taşıma; tazminattan indirim sebebi |
| **Güvence Hesabı** | Sigortasız/plakası tespit edilemeyen araç, tasfiye hâlleri için güvence (5684 m.14) |
| **Basamak sistemi** | ZMSS priminde hasarsızlık geçmişine göre indirim/artırım |
| **Riskli Sigortalılar Havuzu** | Poliçe bulamayan risk gruplarının dağıtıldığı havuz |
